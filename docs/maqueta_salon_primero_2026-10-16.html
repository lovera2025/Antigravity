Después, el sorteo de siempre

  • Con el salón guardado y las 132 mesas puestas, SORTEO ▾ sortea por división sobre ese plano. No cambia nada del motor.
  • Hasta el sorteo, el plano muestra solo números; quién está en cada mesa aparece recién con el sorteo (ya es así hoy).
  • Si entró alguien tarde: Acomodar → "Agregar mesa" y SORTEO vuelve a sortear solo a los que faltan (ya existe).
  • Para empezar de cero: "Deshacer sorteo" y después "Vaciar el salón". Queda el espacio armado; las mesas se vuelven a acomodar con un botón.
  • Un espacio armado para otro predio se puede guardar con nombre ("Buena Vista", "Puerto Viejo") y elegir desde Estilo y armado para la próxima fiesta ahí.
LO QUE NO CAMBIA

La base y la nube no se tocan (es el mismo JSON de armado_json y config; el borde del hormigón ya se guarda por esquinas). Todo lo que guarda el salón sigue pidiendo modo jefe. Los armados del Canva siguen estando para quien los quiera.
