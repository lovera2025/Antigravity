# Ideas

Índice de ideas para implementar más adelante. Una idea por archivo.

No es un backlog de tareas ni una promesa de que se vaya a hacer: es donde
queda pensado lo que ya se discutió, para no volver a discutirlo desde cero
dentro de seis meses.

Para lo que **sí** se decidió hacer y quedó postergado, la carpeta es
[pendientes/](../pendientes/PENDIENTES.md).

## Cómo se usa

- Una idea = un archivo `.md` en esta carpeta, en kebab-case.
- Cada archivo arranca con un encabezado de estado (idea / relevado / en curso
  / descartado) y la fecha de la última revisión.
- Acá adentro va una línea por idea con el enlace y un gancho de una frase.
- Si una idea se descarta, no se borra el archivo: se marca `descartado` y se
  escribe **por qué**. El motivo vale más que la idea.
